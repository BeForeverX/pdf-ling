# PDF Ling

免费在线 PDF 编辑器 — 无需注册，无需上传，浏览器本地处理。

## ✨ 功能

- ✏️ 添加文字（自定义字号、颜色）
- 🖊️ 画笔标注 / 高亮
- 🧹 橡皮擦
- 📎 合并多个 PDF
- ✂️ 拆分指定页面
- 🔄 旋转 / 删除 / 重排页面
- 💾 导出下载
- ↩️ 撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z）

## 🔒 隐私

所有操作在浏览器本地完成，文件不会上传到任何服务器。关闭页面，文件即消失。

## 🚀 使用

直接打开 [index.html](https://beforex.github.io/pdf-ling/) 即可使用，无需安装。

## 技术栈

- [PDF.js](https://mozilla.github.io/pdf.js/) — PDF 渲染
- [pdf-lib](https://pdf-lib.js.org/) — PDF 编辑
- 纯前端，零后端
